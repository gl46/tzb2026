# ADR-0000: M0-R rebaseline project priorities

Date: 2026-07-15 (Asia/Shanghai)
Status: accepted by the M0-R execution baseline

Any former decision treating Cosmos3-Super as the sole primary Teacher is superseded. P0 is a
Gazebo Harmonic + ROS 2 closed loop with an independent data protocol, B1 baseline and Student
boundary. P1 evaluates optional Teacher candidates behind an adapter. P2 Cosmos3-Super is
`PARKED / RESEARCH_REFERENCE / REQUIRES_EXPLICIT_HUMAN_REACTIVATION`.

No Teacher may block P0. The world model remains central: it predicts candidate action outcomes,
ranks candidates with uncertainty gating, compares prediction with observation, attributes failure,
and selects recovery. A human ADR is required to make any Teacher active.
