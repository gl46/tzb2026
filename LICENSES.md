# Third-party licenses and source boundaries

This repository contains original scaffold code only. Upstream names and URLs are locked in
`configs/upstream.lock.yaml`; their licenses remain authoritative at their official sources.

NVIDIA Cosmos3-Nano is audited as `openmdw1.1-license` according to its official model card.
Boundless World Model code and its checkpoint must be evaluated independently: no checkpoint
license is inferred from a GitHub repository license. No model weight, upstream checkout, or
license-acceptance artifact is committed here.
