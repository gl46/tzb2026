## 1. 路线定型

```text
模型层   冻结 Qwen3.8-27B 多模态;不加载 LoRA;不再做训练实验
决策层   公开输入整理 → 任务路由 → 上下文装配 → 结构化分解
         → EXECUTE / REFUSE / RECOVER → 失败后重新决策
安全层   TaskSpec + world snapshot → 语义验证器 → 计划哈希绑定 → REJECT 后被拒计划未到达末端原语 dispatcher 调用点
执行层   抓取候选合成 / IK / 碰撞 / 接触门 / Franka 原语
```

**LoRA 处置**:封存为**消融证据**,不再作为系统组件。adapter tree `8a09f56a…` 保留为可审计工件。

**决策层负责**:抽取目标/目的地/约束/禁止条件;判断执行、拒绝还是恢复;把复杂指令分解为符号计划;**依失败原因重新分解**而非硬跑旧计划;向验证器提交可检查的计划。
**决策层不负责**:输出关节值或轨迹;猜内部数据库 ID;自行宣布任务成功;**自行判定自己的计划是否安全**。

## 3. 公开路由器(消除示例选择泄漏)

现行 `two_shot_family_first_v2` 用 `row.family` 选同类示例,而 `family` 与答案类型强相关。**下一版路由只允许读取模型运行时合法可见的内容**:用户指令、已注册对象与目的地、当前失败码、公开世界状态、上一技能执行结果。**禁止读取 gold family 或任何评测标签。**

确定性公开路由示例:
```text
缺少目标?              → REFUSAL 示例
存在执行失败?          → RECOVERY 示例
目标与目的地均已注册?  → RELOCATION 示例
否则                   → 通用示例
```
或由基座先做一次**只输出公开类别**的路由,再据类别装配示例;**路由结果本身须单独评测**。

## 4. 三类小而精的数据(均**不用于改权重**)

1. **上下文示例库** — 推理时参考。每类任务少量高质量正例:合法执行 / 应当拒绝 / 局部恢复 / 恢复耗尽后重分解 / 目标或目的地有歧义 / 世界状态已变化。**关键不是多,而是每个示例承担不同的决策边界。**
2. **冻结回归集** — 证明加了决策层没有误伤原有能力。现有 P2(合法误拒 0/24、不安全误放 0/24、错误定位 44/44、被拒计划未到达末端原语 dispatcher 调用点 24/24)是其中一部分,但**不能证明通用语言理解未下降**,需补 §2 的基线对照。
3. **失败案例库** — 转化为恢复策略 / few-shot 示例 / 验证规则 / 回归测试 / TaskSpec 约束。
   **硬限制**:**只能取自 DEV 或训练侧的失败。**取评测集失败案例转成示例或规则,即为拟合测试集。此条先于实施写入,不得事后补。

## 5. 每次决策层改动必过的六道门

| 门 | 验收条件 |
|---|---|
| 基座身份 | 同一权重,不加载 adapter |
| 合法任务保持 | 冻结合法集**不得新增误拒** |
| 安全增量 | 不安全计划误放**不得增加** |
| 系统行为 | 被拒计划未到达末端原语 dispatcher 调用点;计划修改后必须**重新验证** |
| 上下文预算 | prompt / 图像 token / 示例 / 输出总长**不得导致关键输入被截断** |
| 降级回退 | 无法形成合法契约时返回结构化 `REFUSE`/`RECOVER`,**不得输出半截 JSON 或任意动作** |

## 6. 其余 vNext 项(排序不代表优先级已定)

- **非特权视觉评测**:P3 修正设计(target-blind overlay、hard negative 机器判据、content-mask 干预、`UNRESOLVED` 输出、六项分列指标、n 分层披露)。**必须在特权仿真真值不得进入 test-time policy input 的永久硬边界下重做**,详见 S5 的 P3 规格。
- **运行时重关联握手**:重新观察 → 重新绑定 → 重新规划 → 再过执行前验证链。当前明确未实现。
- **修复后全新物理 campaign**(B1-FRESH):从 ordinal 0 起新预注册 12 发,**绝不把旧 5 发与修复后新发拼成 12**。
- **协议设计门**:冻结时跑一次**全终态可达性检查**,并在每个新结果进入后自动重算剩余终态。这是 `advance_count=0` 那次暴露的设计缺口的正确修法。
- **任务分布拓宽**:现有单一任务族已证不足(判定信息集中于文本字段、视觉族统计不可识别)。新任务族的可识别性要求:候选必须单线索不足;期望答案**不得**要求输出输入中不存在的 ID。
- **基座可替换性验证**:换一个基座跑同一套 48 例契约门。当前只可称"架构通过符号合同接口分层";**尚未做跨基座替换测试,不得声称可替换性已验证**。
- **决策裁定的工具化门控**(`decision.yaml` + lint + 独立确认 + activation receipt):9/3 后再议。冻结前只采纳其行为部分(五类裁定的执行前六项核验)。
