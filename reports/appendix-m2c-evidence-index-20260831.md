> **顶部签字范围**：本包可独立核验:Tier A 内部一致性、M2C campaign 与 Task32 证据链、冻结 48 例套件定义(原始冻结件)、P2 执行结果 / 规则覆盖 / 当前冻结实现回归(2026-08-31 重导出件,非原始运行)、单个 P2 结构见证案例,以及从 node2 只读取回并经 13/13 源端-拷贝摘要一致性核验的逐族、三 split LoRA 与 adapter 身份原始冻结件。
> **不在本包签字范围**：79.2 MB adapter_model.safetensors 按体积声明性排除；包内身份绑定是报告记录而非推理进程运行时权重证明。LoRA 主 split 区间显式不稳定,只支持‘未检出收益,也未检出退化’,不证明能力未下降；BLIND 视觉 0/12 是任务可辨识性缺陷证据,不是模型视觉能力测量。

本索引把**期望引用摘要**与**当前字节回算摘要**分开。摘要只证明字节身份；`claim_id`、证据状态与 scope 才限定这些字节支持什么主张。

版本说明：v6 是 v5 之后的新 create-once 包；v1/v2/v3 均为 `PROCESS_RECORD_DO_NOT_DELIVER`，v4 与 v5 均保留且不覆写。v6 保留 v5 全部 30 个 claim-bearing evidence bytes，只纳入 consult7 的一处预声明陈旧计数更正并重建索引/MANIFEST；当前三态仍为 13/8/0。另有一个 0B 的 v6 baseline-v1 过程记录：该路径从未承载过基线内容；0B 是 shell 重定向截断的产物，不是一次内容为空的基线。它标为 `PROCESS_RECORD_DO_NOT_USE` 并保留不覆写。
## 核验与对象类型

- `expected_reference_sha256`：来自独立历史绑定或经验证的 S5 handoff；不是从 package copy 反推。
- `expected_frozen_sha256`：仅在该引用确为原始冻结/批准字节时填写；重导出件明确写 `NOT_APPLICABLE_REDERIVED_OUTPUT`。
- `current_sha256`：对当前 source bytes 重新计算。
- `match`：`current_sha256 == expected_reference_sha256`；任何 `false` 都是停止条件。
- `FILE_BYTES_SHA256`、`PUBLICATION_SHA256`、`CANONICAL_TREE_SHA256`、`GIT_COMMIT`、`ARCHIVE_SHA256` 是不同对象域，禁止跨域比较。
- Tier B claim-bearing 文件统一标 `DISTRIBUTION_COPY_NOT_AUTHORITY`；原始冻结件与重导出件的证据强度由 `evidence_state` 分开。
- Tier A 统一标 `POST_HOC_PRESENTATION_ARTIFACT`，不得与冻结实验工件混列。
- 包内相同重导出报告可按两个 class-local 路径发行；计数按 MANIFEST member，不按唯一字节摘要。
